# Profile README variations

Three layouts to choose from. Each can be adopted as-is, or you can mix sections
between them.

| Variation | Style | Best for |
| --- | --- | --- |
| [V1 — Minimal](v1-minimal.md) | Text-first, no images | A clean, recruiter-friendly profile |
| [V2 — Visual](v2-visual.md) | Photo banner, project cards, screenshots | Showing off front-end work visually |
| [V3 — Terminal](v3-terminal.md) | Terminal intro, skill icons, GitHub snapshot | A developer-branded, stats-focused profile |

Rendered previews: [V1](previews/v1-minimal.png) · [V2](previews/v2-visual.png) · [V3](previews/v3-terminal.png)

## Sections by variation

| Section | V1 Minimal | V2 Visual | V3 Terminal |
| --- | --- | --- | --- |
| Header | Text name + role | Photo banner + social badges | Terminal block + text links |
| About | Paragraph + bullets | Paragraph + bullets | Terminal `whoami` output |
| Tech stack | Inline code tags | Shields.io badges | Skill icons |
| Projects | Table with live links | 2x2 screenshot cards | Headed list with code tags |
| GitHub stats | None | Activity card | Activity card |
| Education | Yes | No | No |
| Currently building | Yes | Yes | Yes |
| Contact | Text links | Badge buttons | Badge buttons |

## Mix and match

You can combine sections, for example:

- V2 banner + V1 projects table + V3 stats
- V1 header + V2 project cards + V3 skill icons
- V3 terminal intro + V2 featured work + V1 education

Tell me which sections you want and I will assemble the final `README.md`.
